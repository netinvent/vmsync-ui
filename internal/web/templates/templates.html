Schedule templates

A template is a named cadence and profile that schedule entries inherit from. Setting one field on a VM overrides just that field; everything else comes from here.

{{if $v.HasDefault}}

The default template also covers every VM that has no entry of its own — but only where a successful sync has already recorded a target, so it never reaches a pair nobody has established by hand.

{{else}}

There is no default template, so automatic coverage is off: a VM is replicated only if somebody gives it an entry on the Schedule page. Creating one named default turns it on.

{{end}}

Templates resolve on the agent, not here — a standalone agent has no console at all — so this page cannot show what any particular VM ends up with. The Schedule page shows that, as each agent reports it back.

Add or replace a template

Saving under an existing name replaces it. Every VM inheriting that template changes with it, on each agent's next check-in.

How often to verify

Leave all three blank to verify on every sync. Use an interval or a calendar, never both — the agent refuses a template carrying both, because there is no reading of "every 24 hours, and also the first Sunday" anyone could predict.

Sun *-*-01..07 with 02:00-12:00 is the first Sunday of the month, between 2am and noon, in each agent host's own timezone. The calendar's spelling is checked by the agent, not here — an expression this page accepts can still be refused there, and the Schedule page shows it when that happens.
